# Design do jogo — Figma simples

Este documento funciona como um guia visual básico para o conceito do jogo, em estilo Figma/board de design. A ideia é resumir a composição, elementos principais e identidade visual do projeto.

## Layout principal

```text
┌────────────────────────────────────────────────────────────────────┐
│ MEDIEVAL ARENA · 2D                                                  │
│                                                                    │
│  [Ignis HP]                     [VS]                     [Azur HP] │
│  ──────────────────────────────────────────────────────────────── │
│                                                                    │
│  [CENÁRIO / ARENA MEDIEVAL]                                        │
│  [Dragão vermelho à esquerda]     [Dragão azul à direita]          │
│                                                                    │
│  [Botão: pausa]                                                    │
│                                                                    │
│  Controles: A D move | W pular | J garras | K fogo | L defender    │
│                                                                    │
│  [Música: ligada]  [Volume]                                        │
└────────────────────────────────────────────────────────────────────┘
```

## Paleta sugerida

- Vermelho principal: #d94b2b
- Azul adversário: #3aa6d8
- Dourado de detalhes: #d7b36a
- Fundo arena: #101b2b
- Texto principal: #f4e5c4
- Barra de energia: #ffcc66
- Barra de vida: verde/dourado/laranja

## Elementos principais

### 1. Dragão vermelho (Ignis)
- personagem do jogador
- silhueta agressiva
- detalhes quentes, fogo e escamas vermelhas
- foco em ação ofensiva

### 2. Dragão azul (Azur)
- adversário controlado pela IA
- paleta fria para contrastar com o vermelho
- atuação defensiva e de pressão

### 3. Arena
- fundo medieval com atmosfera sombria
- espaço central amplo para leitura do combate
- destaque para pernas, janelas de impacto e projéteis

### 4. HUD
- vida do jogador e do adversário
- energia do jogador e do adversário
- textos de status
- controle de pausa e música

## Fluxo de jogo

```text
Tela inicial
   ↓
Botão “Start duel”
   ↓
Arena ativa
   ↓
Combate / alavanca movimento + ataque + defesa
   ↓
Vitória / derrota / empate
   ↓
Botão “Play again”
```

## Direção artística

- Visual esportivo e avassalador
- Legibilidade rápida do combate
- Alto contraste entre jogadores
- Combo de leitura de ação e interface mínima

## Observação

Este é um esboço de design conceitual, não um arquivo Figma nativo. O objetivo é deixar uma referência visual simples para a identidade do jogo e para futuras melhorias de UI/UX.
